# Patitas Ya — catálogo simple

Versión simplificada de la tienda pública.

## Cambios principales

- El inicio abre directamente con buscador, categorías y catálogo.
- El buscador revisa palabras dentro del **nombre del producto**.
- Se eliminaron de la portada el hero grande, destacados, filtros laterales y accesos a WhatsApp.
- Las categorías funcionan como botones medianos y rápidos.
- El cliente arma una lista de productos sin salir del catálogo.
- Al finalizar completa nombre, teléfono, dirección, medio de pago y comentario opcional.
- El pedido se envía a Google Sheets mediante Google Apps Script.
- Google Apps Script puede enviar una notificación por correo por cada pedido nuevo.

Para activar el registro de pedidos revisa `INSTALACION_PEDIDOS.md`.
